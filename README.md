# Loopkaart Limburg

Buurtkaart van Nederlands Limburg voor huis-aan-huis lopen: per buurt budget (WOZ, koopwoningen, inkomen), zonnepanelen en hoe dicht de huizen op elkaar staan.

- Heel Limburg: `index.html`
- Zuid-Limburg: `zuid/index.html`

Wat je op de kaart bijhoudt (gepland, gelopen, niet thuis, notities) blijft in je eigen browser.

Bronnen: CBS Kerncijfers wijken en buurten 2024 en 2023 via PDOK, wegen en plaatsnamen © OpenStreetMap-bijdragers.
